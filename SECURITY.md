# Security Policy

## Reporting a vulnerability

The Oumi team takes security bugs seriously, and we appreciate responsible disclosure.

To report a security issue, use the GitHub Security Advisory ["Report a vulnerability"](https://github.com/oumi-ai/oumi-plugins/security/advisories/new) tab. Please don't open a public issue.

We'll reply with next steps, keep you informed while we work on a fix, and may ask for more details.

This repository holds plugin manifests only. Vulnerabilities in the Oumi platform or its MCP server at `api.oumi.ai` can be reported the same way.

## Acknowledgements

We'll credit you in the advisory unless you prefer to stay anonymous.
